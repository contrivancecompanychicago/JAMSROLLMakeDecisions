# JAMSROL
Java Atoms Molecules Science Resource Ontology Language

## Version 0

`erichilarysmithsr/JAMSROL` is designated as Version 0 of the JAMSROL system. The medical supply-chain backend for JAMSROL is maintained in [`make-DEEP-Human-Families-Healthy/pirddiiqlab`](https://github.com/make-DEEP-Human-Families-Healthy/pirddiiqlab).
